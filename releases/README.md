# Versionen der fertigen Seite

In diesem Ordner liegen fertige Fassungen der Webseite zum Herunterladen und Hochladen bei einem Hoster.

- Jede Version hat einen eigenen Ordner: `v1/`, später `v2/` und so weiter. Eine Version wird nie überschrieben.
- In jedem Versionsordner liegen vier Dateien:
  - `catchup-seite-vX.zip`: die ganze Seite in einer Datei. Diese Datei lädst du beim Hoster hoch.
  - `PRUEFSUMME.txt`: eine lange Zahl, mit der du prüfst, dass die ZIP beim Herunterladen nicht beschädigt wurde.
  - `INHALT.txt`: welche Dateien in der ZIP stecken, wie viele und welche die größte ist.
  - `VERSION.txt`: Datum, zugehöriger Stand im Repository und ob die Seite noch Platzhalter enthält.
- `AKTUELL.md` listet alle Versionen in einer Tabelle, die neueste unten.

Eine ZIP ist eine gepackte Datei, die viele Dateien und Ordner in einer einzigen Datei zusammenfasst.

Die Schritt-für-Schritt-Anleitung (herunterladen, prüfen, hochladen, neue Version) steht in [START-HIER.md](../START-HIER.md) im Hauptordner.
